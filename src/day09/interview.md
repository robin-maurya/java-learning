# Day 09 Interview Questions

## 1. What is Encapsulation?

Encapsulation is the process of hiding data and providing controlled access using getter and setter methods.

---

## 2. What are Access Modifiers?

Keywords that define the accessibility of classes, methods, and variables.

---

## 3. Name the four Access Modifiers.

- public
- private
- protected
- default

---

## 4. What is a Getter?

A method used to return the value of a private variable.

---

## 5. What is a Setter?

A method used to update the value of a private variable.

---

## 6. Why do we use private variables?

To protect data from direct access.

---

## 7. What is the return type of a Setter?

void

---

## 8. What is the return type of a Getter?

Same as the variable type.

---

## 9. Why is Encapsulation important?

- Data Security
- Controlled Access
- Better Maintenance

---

## 10. Difference between Getter and Setter?

| Getter | Setter |
|--------|--------|
| Returns value | Updates value |
| Has return type | Usually void |
| Read operation | Write operation |
