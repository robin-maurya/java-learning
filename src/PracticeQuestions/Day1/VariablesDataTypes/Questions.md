# Level 1 — Variables & Data Types
1. Create an int variable to store your age and print it.
2. Create variables for your name, age, height, and whether you are a student. Print all of them.
3. Store two numbers in variables and print their sum.
4. Store the price of a product and quantity. Print both.
5. Create variables for byte, short, int, long, float, double, char, and boolean. Print each value.
