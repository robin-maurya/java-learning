# Day 10 Interview Questions

## 1. What is Inheritance?

Inheritance is the process of acquiring properties and methods of one class into another class.

---

## 2. Which keyword is used for Inheritance?

extends

---

## 3. What is a Parent Class?

A class whose properties and methods are inherited.

---

## 4. What is a Child Class?

A class that inherits another class.

---

## 5. What is Method Overriding?

Providing a new implementation of an inherited method.

---

## 6. What is @Override?

An annotation that indicates a method overrides a parent class method.

---

## 7. What is super keyword?

Used to access parent class methods and constructors.

---

## 8. What is Code Reusability?

Using existing code instead of writing it again.

---

## 9. Can Java support multiple inheritance with classes?

No.

Java supports only Single Inheritance with classes.

(It supports multiple inheritance using interfaces.)

---

## 10. Difference between Inheritance and Encapsulation

| Inheritance | Encapsulation |
|-------------|---------------|
| Reuses code | Hides data |
| Uses extends | Uses private |
| Parent → Child | Getter & Setter |
