# Day 06 Interview Questions

## 1. What is a Method?

A method is a block of code used to perform a specific task.

---

## 2. Why do we use Methods?

- Code Reusability
- Readability
- Maintainability
- Reduce Duplication

---

## 3. What is the difference between Parameter and Argument?

Parameter

Declared in method definition.

Example

```java
String name
```

Argument

Passed during method call.

Example

```java
greet("Robin");
```

---

## 4. Difference between void and return?

void

Returns nothing.

return

Returns a value.

---

## 5. What is Method Overloading?

Method Overloading means multiple methods having the same name but different parameters.

---

## 6. Can methods be overloaded only by changing return type?

No.

Return type alone cannot overload methods.

---

## 7. What is the difference between Method Definition and Method Call?

Definition

```java
static void greet(){

}
```

Call

```java
greet();
```

---

## 8. What is return keyword?

return sends a value back to the calling method.

---

## 9. Can a method return multiple values?

No.

A method returns only one value.

---

## 10. What is Compile-time Polymorphism?

Method Overloading is known as Compile-time Polymorphism.
