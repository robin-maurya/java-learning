# Day 07 Interview Questions

## 1. What is String?

A String is a sequence of characters used to store text.

---

## 2. Difference between char and String?

char stores one character.

Example:

char grade = 'A';

String stores multiple characters.

Example:

String name = "Robin";

---

## 3. What does length() return?

Returns total number of characters.

---

## 4. Difference between length() and length?

String -> length()

Array -> length

---

## 5. What is charAt()?

Returns character at a specified index.

---

## 6. Difference between equals() and equalsIgnoreCase()?

equals()

- Case-sensitive

equalsIgnoreCase()

- Case-insensitive

---

## 7. What does contains() return?

Returns boolean.

true

or

false

---

## 8. How does substring() work?

substring(start)

substring(start,end)

Start index Included

End index Excluded

---

## 9. Are Java Strings mutable?

No.

Strings are immutable.
